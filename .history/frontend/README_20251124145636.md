✔ 1.2 Node.js

React çalıştırmak için Node.js şarttır.
npm de Node ile birlikte gelir, ekstra kurulum gerekmez.

🔍 Node kurulu mu kontrol:
node -v

❗ Node yoksa Google’dan indir:

Google → Node.js download

👉 https://nodejs.org

🟦 2. React Projesini Create React App ile Başlatma

CRA, React’ın klasik ve resmi proje başlatma yöntemidir.

Terminali aç: Klasörünün olduğu dizine git. cd komutu ile. o dizindeyken:

📌 2.1 Proje oluşturma
npx create-react-app frontend

(İstersen proje adını değiştirebilirsin.)

Bu komut şunları otomatik yapar:

React kurulumu

React DOM kurulumu

Webpack

Babel

Gerekli tüm config dosyaları

📌 2.2 Proje klasörüne gir
cd frontend

📌 2.3 Projeyi çalıştır
npm start

Varsayılan çalışma adresi:

👉 http://localhost:3000/

📦 5. Gerekli Kütüphanelerin Kurulumu
React Router:
npm install react-router-dom

Axios:
npm install axios

Redux Toolkit:
npm install @reduxjs/toolkit react-redux

6 ve 7 yi sonra yapabiliriz. Anlayamadım.
🏗 6. Production Build Alma
npm run build

Bu komut şu klasörü oluşturur:

build/

Bu klasör Nginx, Apache, Docker, Render veya herhangi bir hosting platformunda yayınlanabilir.

📥 7. Build’i Lokal Olarak Test Etme (İsteğe Bağlı)

CRA kendi preview komutunu içermez, bu nedenle:

npm install -g serve
serve -s build

Test adresi:

👉 http://localhost:3000/

♻️ 8. Temiz Kurulum (Hatalar İçin)
rm -rf node_modules
rm package-lock.json
npm install

Windows için:

rmdir /s /q node_modules
del package-lock.json
npm install

🐞 9. Sık Karşılaşılan Hatalar
❗ npm: command not found

Node.js YOK → Node kur.

❗ npx: command not found

Node/npm bozuk → Node'yi yeniden kur.

❗ error: port 3000 is already in use

Çözüm:

kill-port 3000

ya da Windows için:

netstat -ano | findstr 3000
taskkill /F /PID <PID>
